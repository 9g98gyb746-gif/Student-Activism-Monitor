Student activism monitor

Automated news scan for reports of repression and attacks against student activists, via the GDELT Project. Every item here is a lead to check, not a confirmed incident.

Data from the public GDELT Project Web NGrams dataset. Stories reported by several outlets are grouped into one line. Filters and regions are keyword-based, so they are a guide, not a guarantee.

Items marked “weak match” mention a repression term only far from the student-activism phrase; they are left out of the counts at the top.

The monitor reads English-language sources only, so countries with little English coverage can look quiet even when a lot is happening. See the repository README for methodology and limitations.
