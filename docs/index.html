Student activism monitor

Automated news scan for reports of repression and attacks against student activists, via the GDELT Project.

This pilot is part of SAIH’s ongoing work to raise awareness of attacks on student activism worldwide. It is a work in progress: stories are found automatically through keyword matching, and AI tools were used to help build it. The results are not verified incidents, and some stories will be wrong or missing.

Data from the public GDELT Project Web NGrams dataset. Stories reported by several outlets are grouped into one line. Filters, regions and topics are keyword-based, so they are a guide, not a guarantee.

Items marked “weak match” mention a repression term only far from the student-activism phrase; they are left out of the counts at the top.

The monitor reads English-language sources only, so countries with little English coverage can look quiet even when a lot is happening. See the repository README for methodology and limitations.
